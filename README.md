# Soniqum releases

**RU.** Здесь публикуются сборки Soniqum — редактора аудиотегов для macOS — и лента обновлений; исходный код приватный. Скачайте `Soniqum-X.Y.Z.dmg` со страницы [Releases](https://github.com/Venut-Technologies/soniqum-releases/releases/latest), откройте его и перетащите `Soniqum.app` в «Программы»; дальше приложение обновляется само через Sparkle по ленте [`appcast.xml`](https://venut-technologies.github.io/soniqum-releases/appcast.xml). Если релиз помечен как pre-release (не нотаризован), первый запуск заблокирован Gatekeeper — открыть через Системные настройки → Конфиденциальность и безопасность → «Всё равно открыть».

**EN.** This repository hosts Soniqum builds — an audio tag editor for macOS — and its update feed; the source code is private. Download `Soniqum-X.Y.Z.dmg` from [Releases](https://github.com/Venut-Technologies/soniqum-releases/releases/latest), open it and drag `Soniqum.app` into Applications; after that the app updates itself through Sparkle using the [`appcast.xml`](https://venut-technologies.github.io/soniqum-releases/appcast.xml) feed. If a release is marked pre-release (not notarised), macOS blocks the first launch — open System Settings → Privacy & Security → Open Anyway.

Requirements: macOS 15 or later, Apple Silicon.
